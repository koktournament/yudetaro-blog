プロレスの「不穏試合」を集めた。試合の枠を超えて空気が凍った試合、ガチ化・シュート化した試合、制裁、ブック破り。ただし条件はひとつ、**今YouTube等で動画が見られるものだけ**。見られない試合は、どんなに有名でも入れていない。

国内22試合は、私の判断で【ブック破り】【不穏試合】【シュート】【制裁】に分類した。海外15試合は分類なしで並べてある。

動画リンクは2026年11月16日時点で見られることを確認したものだけど、非公式のアップロードは予告なく消える。**リンク切れを見つけたら、コメント欄で教えてください。「この試合も入れてほしい」という追加希望も歓迎です。**名前だけで投稿できます。

## 1950年代〜1970年代

**1. 1954年12月22日　力道山 vs 木村政彦【ブック破り】**
究極の不穏試合。ブックを破って力道山が仕掛けた試合だ。元祖シュート試合とされる一戦で、引き分けで終わらせる取り決めがあったとされるが、木村の金的蹴りをきっかけに力道山が本気の打撃で一方的に攻め、1本目15分49秒TKOで木村を倒した（結果は力道山の2-0）。戦後プロレスの方向を決定づけた事件として語り継がれている。
{{< youtube 9oNac-RHEIk >}}

**2. 1976年6月26日　アントニオ猪木 vs モハメド・アリ【不穏試合】**
内容は諸説あるが、試合が行われたこと自体と、そこに至る経緯がすさまじい。来日したアリ陣営から、立った状態でのキック、チョップ、投げ技、関節技などを禁じる、猪木に著しく不利な特別ルールが突き付けられた。猪木はマットに背中や膝をついた姿勢からアリの脚を蹴り続ける戦法（後の「アリキック」）に活路を見出し、アリのパンチは15ラウンドで数発にとどまった。結果は判定引き分け（1-1）。当時は「世紀の凡戦」と激しく批判されたが、猪木は右足の甲を剥離骨折し、アリも脚に血栓ができて一時切断の危機に陥るなど、実際には命がけの削り合いであり、後の総合格闘技の原点と評価されている。
{{< youtube 6S7UCSwpe9U >}}

**3. 1976年8月7日　ウィレム・ルスカ vs イワン・ゴメス【シュート】**
何でもありのバーリトゥード形式で行われたセメントマッチ。壮絶な内容で語り草になっている。
{{< youtube w5u-ManDtY0 >}}

**4. 1976年12月12日　アントニオ猪木 vs アクラム・ペールワン【シュート】**
猪木が腕を折ったとされる伝説のシュート。アリ戦で世界的に有名になった猪木に、パキスタンの国民的英雄ペールワンが挑戦した一戦で、試合の数時間前にペールワン陣営から「ノーブック勧告」が突き付けられたとされるセメントマッチである（ルールは出典により異なり、5分6ラウンド制とも、1ラウンド3分の5ラウンド制で2本先取とも伝えられる）。2ラウンドにペールワンが猪木の腕に歯型が付くほど強く噛みつき、猪木は目つき（親指を目に突き入れる）で応戦。3ラウンド、猪木のチキンウィングアームロックが完全に極まったがペールワンはギブアップせず、左肩と左肘を脱臼させられ、3ラウンド1分5秒、ドクターストップで敗れた。レフェリーのミスター高橋は、フィニッシュは台本通りではなかったと証言している。ペールワンはこの試合で片目を失明したともいわれ、同年限りで現役を引退した。猪木には藤原喜明が帯同していた。
{{< youtube XKEKMooFrpE >}}

**5. 1977年12月8日　アントニオ猪木 vs グレート・アントニオ【制裁】**
怪力自慢のグレート・アントニオが猪木の技を受けず挑発を繰り返したため、猪木が本気の顔面キックなどを連発して制裁。3分49秒、KOで猪木の勝利。プロレスの暗黙の了解を破った者への「制裁」の代表例とされる。
{{< youtube v7NXgvG184Y >}}

## 1980年代

**6. 1980年2月27日　アントニオ猪木 vs ウィリー・ウィリアムス【不穏試合】**
プロレスである。ただし雰囲気とヤバさはガチンコ以上で、緊張感も異常。何があってもおかしくないプロレスなので、ガチンコよりヤバい。極真空手の「熊殺し」ウィリーとの異種格闘技戦。両陣営の不穏な空気の中、試合はセコンド乱入の大混乱となり、4ラウンド両者ドクターストップの引き分け。猪木は肋骨を骨折、ウィリーも腕を負傷した。猪木はこの試合を最後に異種格闘技戦を封印した。事前に打ち合わせがあったとする証言もあり、真偽は諸説ある。
{{< youtube 3VSvGysa_jI >}}

**7. 1983年6月2日　アントニオ猪木 vs ハルク・ホーガン（舌出し失神事件）【不穏試合】**
不穏試合風のプロレス。エプロン際でホーガンのアックスボンバーを受けた猪木が場外に転落し、舌を出したまま失神。セコンドにリングへ戻されるも動かず、21分27秒、ホーガンのKO勝ちとなった。猪木はそのまま救急搬送され、一般紙・テレビニュースでも報じられる大事件となった。ただし現在は、猪木の自作自演だったとする説が半ば定説になっている（セコンドだった藤原喜明は「舌先に力が入っていた。あぁ、芝居してるな」と証言している）。
{{< youtube vpAIraPtnso >}}

**8. 1986年10月9日　前田日明 vs ドン・中矢・ニールセン【シュート？】**
前田がキックボクサーを仕留めたとされる一戦。5ラウンド2分26秒、逆片エビ固めで前田がギブアップ勝ちを収めたが、前田は1ラウンドにニールセンの左ストレートを浴び、記憶が定かでないまま試合を続け、後遺症で次期シリーズを欠場している。ニールセンは後に「流れを決めたわけではなかった。1ラウンドにいいパンチが入ったのに、セコンドに『アーリーノックアウトはダメだ』と言われた」と証言しており（kamipro）、勝敗の行方そのものにシュートの緊張が残る試合だった。この勝利で前田は「新・格闘王」と呼ばれるようになった。もっとも、前田の側から見たら、アンドレ戦の不信感もあり、ニールセンが仕掛けてきたとしか思えないかもしれない。
{{< youtube qqU8IxaC8xM >}}

**9. 1987年7月18日　神取忍 vs ジャッキー佐藤【シュート】**
「日本プロレス史上唯一のセメントマッチ」とも呼ばれる一戦。背景には、1986年8月のジャパン女子旗揚げ戦（神取のデビュー戦）でジャッキーに敗れた神取が、その後のタッグ戦で場外ラリアットにより右目周辺を負傷し、後の試合でジャッキーがその右目を狙ったと認識して一騎打ちを要求した経緯がある。関係者は事前にシュートになると知っていたとされる（レフェリー福士経由の証言）。試合は神取がパンチの連打でジャッキーの顔面を腫れ上がらせ、関節技でも圧倒して腕がらみで完勝。神取は後に「考えていたことは勝つことじゃない。相手の心を折ることだった」と語っている。ジャッキーは翌1988年3月20日の神取との再戦を最後に引退した。
{{< youtube VuNjIVD5TDc >}}

**10. 1987年10月4日　アントニオ猪木 vs マサ斎藤（巌流島決戦）【不穏試合】**
無観客・ノーレフェリー（立会人は坂口征二、山本小鉄）・時間無制限ノールールという異例の決闘。2時間5分14秒に及ぶ死闘の末、猪木が裸絞めでTKO勝ち。両者とも流血し、猪木は肩を脱臼、斎藤は骨折、ともに脱水症状に陥った。試合そのものは取り決めの範囲内だったが、人気も観客もない孤島で2時間殴り合う異常な光景が語り草になっている。
{{< youtube wKIhoB-zIVQ >}}

**11. 1987年11月19日　前田日明の長州力・顔面蹴撃事件（6人タッグマッチ中）【不穏試合】**
事故。キツめに行ったのは間違いないけど、意図的なシュートではない。長州が木戸にサソリ固めをかけた際、カットに入った前田のキックが長州の顔面を直撃。長州は右前頭洞底（眼窩底）骨折で全治1か月の重傷を負った。前田は無期限出場停止処分を受け、処分解除条件のメキシコ遠征を拒否して1988年2月1日に解雇された。前田本人は「肩を叩いて合図したが長州が横を向いた。事故だった」と主張しており、故意か事故かは諸説ある。
{{< youtube p5VzT9cuRJE >}}

**12. 1987年12月27日　ビッグバン・ベイダー vs アントニオ猪木（両国暴動事件）【不穏試合】**
一番不穏なのは当時のファン。たけしプロレス軍団（TPG）の刺客として日本デビューしたベイダーが、当日のカード変更の末に猪木と対戦（猪木は同日、長州力に反則勝ちした直後の2試合目だった）。ベイダーが3分弱（2分49秒とも）でパワースラムによりフォール勝ちを収めると、カード変更と秒殺決着に激怒した観客が暴動を起こし、会場設備が破壊された。新日本プロレスは賠償金300万円を支払い、両国国技館は1989年2月まで使用禁止となった。
{{< youtube q89FfS95dTY >}}

## 1990年代

**13. 1990年8月3日　橋本真也 vs 栗栖正伸【不穏試合】**
超激しいプロレス。ガチとかそういうことではない。新日本プロレスの一戦で、テレビで放送されなかった試合として語り草になっている。
{{< youtube qx_fp5IpjuE >}}

**14. 1991年4月1日　北尾光司 vs ジョン・テンタ（「八百長」マイク事件）【不穏試合】**
元横綱・北尾と元幕下のテンタ（アースクェイク）の元力士対決。北尾はまともに組み合わず、本部席の机を投げる、目つぶしのポーズを取るなどの危険・挑発行為を繰り返し、間に入ったレフェリーを蹴って反則負け。試合後、マイクを奪って「八百長野郎この野郎!八百長ばっかりやりやがって!!」「お前ら、こんなもの観て面白いのか!」と絶叫した。プロレスのタブーを破る発言として大問題となり、北尾は4月4日にSWSを解雇された。
{{< youtube vNXaI8C15lk >}}

**15. 1991年4月1日　鈴木みのる vs アポロ菅原【不穏試合】**
UWF系スタイルの鈴木と、従来型プロレスのアポロ菅原のスタイルが全く噛み合わず、試合が成立しなかった一戦。開始直後から鈴木は張り手、菅原は前蹴りを放ち合ってまともに組み合わず、菅原側がセメント行為を仕掛けたとされ、鈴木はコーナーに追い詰めて頭突き、菅原はグーパンチで応戦する泥沼の様相となった。レフェリーが双方の反則に注意を入れた直後、菅原は試合を放棄するようにリングを降り、そのままゴングが鳴って鈴木の勝ちとなった。会場は大ブーイングに包まれ、レフェリーと菅原の口論が始まり、鈴木も感情を剥き出しにマイクで叫び返すなど場内は騒然となった。両者の和解は伝えられていない。
{{< youtube 5mAQneONf18 >}}

**16. 1991年12月22日　高田延彦 vs トレバー・バービック【ブック破り】**
元プロボクシング世界ヘビー級王者との異種格闘技戦。バービックが途中で試合を放棄した。
{{< youtube 0CAfqmtZkC8 >}}

**17. 1992年10月23日　高田延彦 vs 北尾光司【ブック破り】**
北尾側が事前に負けブックを拒否し、関節技禁止・引き分け決着などのルール変更を要求して成立した一戦。結果は3ラウンド0分46秒、高田の右ハイキックで北尾がKOされ、高田の勝利。Uインター取締役の鈴木健は「打撃はシュートでOKと決まっていた」と証言しており、無警戒だった北尾を高田が本気のキックで仕留めたとする見方もあるなど、説明には諸説がある。
{{< youtube go1ZKA9xSfs >}}

**18. 1995年6月18日　田村潔司 vs ゲーリー・オブライト【シュート】**
オブライトがシュートを仕掛けたとされる一戦。田村が9分44秒にスリーパーホールドで勝利し、オブライトはノーギャラと2大会の出場停止処分を受けた。
{{< youtube 3Tlm27SvNww >}}

**19. 1997年10月　川田利明 vs 高山善廣【不穏試合】**
「最初の5分をシュートで申し合わせた」と言われるが、そんなわけはない。Uスタイルで行っただけ。川田が対応できなかった。結果はブック通り。
{{< youtube 19UZoFbBqGk >}}

**20. 1999年7月17日　ザ・グレート・サスケ vs ダートバイク・キッド【制裁】**
制裁。覆面リーグ戦にもかかわらずキッドが自らマスクを脱ぎ、打ち合わせより多くの見せ場を奪い、決め技の回転蹴りをノーセルするなどブックを破った（本人も後に意図的だったと認めたとされる）。怒ったサスケは本気の蹴りでキッドを攻め、最後は首への絞め技でタップを奪い2分29秒で決着。試合後、サスケはファイティングポーズを取って構え、キッドの握手を拒否した。キッドの日本でのキャリアはこの試合で事実上終わったとされる。

**22. 2015年2月22日　世IV虎 vs 安川惡斗【不穏試合】**
安川のパンチが世IV虎の顔面に入ったことが発端となり、ノーガードの殴り合いに発展した平成以降の女子プロレス最大の事件。安川は頬骨・鼻骨・左眼窩底の骨折、両目の網膜振盪症で救急搬送された。木村響子のタオル投入で一旦はTKO決着となったが、後に無効試合に変更され、世IV虎は王座剥奪と無期限出場停止処分を受けて同年引退（後に世志琥と改名しSEAdLINNNGで復帰）。安川も視力の回復が困難となり引退した。なお、Dropkick誌には「不穏試合ではない」とする異説もあり、評価には諸説がある。

## 海外編（北米中心・15件）

### カテゴリA＝事件・シュート系（13件）

**23. 1987年1月21日　ブルーザー・ブロディ vs レックス・ルーガー（ケージ内ノーセル事件）**
試合中、ブロディが突然一切の受け身（セル）をやめ、ルーガーの攻撃を全く効かない様子で立ち尽くすようになった。ルーガーはレフェリーのビル・アルフォンソを突き飛ばして反則裁決を引き出し、そのまま金網をよじ登って会場から逃げ出した。ルーガーは後に「本気で怖かった」と語っている。ブロディがなぜそうしたのかは諸説あり（ギャラや待遇への不満、ベビーフェイス同士の対戦への不満、どちらが試合をリードするかの行き違いなど）、真相は確定していない。
{{< youtube -FfngjQyIxM >}}

**24. 1996年11月23日　マス・トランジット事件（ニュージャックのブレーディング事故）**
欠場したアクセル・ロッテンの代役として出場したエリック・クラス（リングネーム「マス・トランジット」）は、実は17歳で年齢を詐称し、トレーニング経験もほぼなかった。クラス本人に頼まれてニュージャックが流血用の切りつけ（ブレーディング）を行った際、外科用メスで深く切りすぎて動脈2本を切断。クラスは大量出血し、父親が「ベルを鳴らせ！こいつは17歳だ！」と叫ぶ騒ぎになった。この事件でECW初のPPV（ベアリー・リーガル）は一時中止の危機に陥り、ニュージャックは刑事裁判にかけられたが無罪となった。クラスは2002年に胃バイパス手術の合併症で亡くなったが、この事件とは無関係とされる。
事件ドキュメンタリー内のファン撮影 {{< youtube O9XdULE9RvE >}}

**25. 1997年11月9日　ブレット・ハート vs ショーン・マイケルズ（モントリオール事件）**
WCWへの移籍が決まっていた王者ブレット・ハートを、ビンス・マクマホンが事前の約束を破って無理やり敗北させる「スクリュージョブ」が実行された。本来の結末は両者反則（DQ）のはずが、マイケルズがハート自身の得意技シャープシューターをかけたところで、ハートがギブアップしていないのにレフェリーのアール・ヘブナーがベルを鳴らして試合を終わらせた。ハートはマクマホンに唾を吐き、バックステージでマクマホンを殴ったとされる。プロレス史上最も有名なブック破りとして、今もドキュメンタリーが作られ続ける事件。
公式 {{< youtube L_72bAYabGI >}}

**26. 1999年3月28日　バタービーン vs バート・ガン（ブロール・フォー・オールの代償）**
1998年に行われたガチの殴り合いトーナメント「ブロール・フォー・オール」で、台本上の優勝候補だったドクター・デス・スティーブ・ウィリアムスをKOして優勝してしまったバート・ガンへの「お仕置き」として組まれたとされる試合。プロボクサーのバター・ビーンにわずか35秒でKOされ、ガンはその後まもなく解雇された。バター・ビーン自身も2023年のインタビューで「お仕置きだった」と認めている。ガチ大会が会社の台本を壊し、その報復まで含めて語り草になっている。
公式 {{< youtube J9fmrvYXgtY >}}

**27. 2000年7月9日　ハルク・ホーガン vs ジェフ・ジャレット（バッシュ・アット・ザ・ビーチ2000）**
ブック担当ビンス・ルッソの指示で、王者ジャレットがリングに寝転んでホーガンにフォールさせた。ホーガンは片足でフォールしながらマイクで「これがお前の考えか、ルッソ。だからこの会社はこんなザマなんだ」と言い放って退場。その後ルッソがシュートマイクでこの勝利を無効化し、同夜にブッカーTがジャレットを破って新王者になった。ホーガンはWCWを去り、ルッソを名誉毀損で訴えた（2003年に棄却）。どこまでが台本でどこからが本気かは当事者の言い分が食い違っており、今も諸説ある。

**28. 2000年3月12日／2002年2月23日　ニュージャック vs ヴィック・グライムズ（足場落下と報復とされる落下）**

**36. 1998年6月28日　ジ・アンダーテイカー vs マンカインド（ヘル・イン・ア・セル）**
試合開始直後、アンダーテイカーが高さ16フィート（約4.9m）のセルの屋根からマンカインドを投げ落とし、スペイン語実況席のテーブルを突き破って落下。実況のジム・ロスが「彼は真っ二つに折れた！」と絶叫した。担架で運ばれかけたマンカインドはそれを振り切って再び屋根に登り、今度はチョークスラムで屋根を突き破ってリングに落下した。この2度目は屋根パネルの崩れ方が想定を超えたもので、マンカインドは一時本当に失神し、顔に当たった鉄イスで歯が鼻に突き刺さった。肩と顎の脱臼、脳震盪、腎臓の打撲、歯の欠損など本物の重傷を負いながら試合は17分38秒まで続き、2度にわたり中止寸前になったが本人の希望で続行された。なおアンダーテイカー自身も足の骨折を抱えて出場していた。ブック通りの試合でありながら「人が死んだのではないか」と会場全体が凍りついた、ヘル・イン・ア・セルの代名詞的一戦。
