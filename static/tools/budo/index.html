武道映像アーカイブ

YouTubeで今も見られる、武道・伝統武術の古い映像だけを集めたアーカイブです。開祖・故人となった達人の演武、歴史的な試合、古流の形の記録フィルム。全155本、すべて実在を確認してから載せています。サムネイルを押すとその場で再生できます（埋め込みが禁止されている動画は、YouTubeへのリンクになっています）。

柔道・合気道・空手・古武道から、中国武術、サンボとシステマ、古式ムエタイ、シラット、そしてランカシャー式キャッチレスリングまで。1897年の剣術フィルムから収録しています。

このアーカイブについて
・収録基準：撮影の古いものを中心に、開祖・故人の達人の記録映像、歴史的な演武・試合、古流の形の記録を選んでいます。現代の格闘技スポーツ（ボクシング、MMA、現代のプロレス等）の試合映像は入れていません。古式ムエタイと、古いキャッチレスリングは収録しています。
・撮影年は、動画のタイトルや説明で明示されている場合のみ表示しています。明示がないものは「年代未確認」としています。
・探しても動く映像が確認できなかったものもあります。不遷流の田辺又右衛門、無相流新柔術、ビリー・ライリー本人、宮城長順・楊澄甫本人の映像は、今回の調査では見つかりませんでした。
・動画の権利は各アップロード者にあります。YouTube側で削除されるとここでも見られなくなります。リンク切れを見つけたら、お問い合わせから教えてください。
・データ確認日：2026年11月26日
