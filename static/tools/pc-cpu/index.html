CPU性能チェッカー

CPUを選ぶだけで ゲーム性能・マルチ性能の指数と、組み合わせるグラボの目安 が一目でわかるチェッカー。現行〜定番の全46 CPUを収録しています。ゲーム指数は PassMark のシングルスレッド性能、マルチ指数は CPU Mark がもとです。

🎮 CPU収録 ⚡ スコア順に並んでいます 🛒 各パーツに Amazon 検索リンク付き

性能ランクの見方ガイド

CPUの性能は「ゲーム性能（シングルスレッド）」と「マルチ性能（コア全体）」の2つで見ます。ゲームはシングルスレッド性能の影響が大きく、動画編集・配信・重い作業はマルチ性能が効きます。

ハイエンド ― マルチ性能が桁違いのライン

Core Ultra 9 285K、Ryzen 9 9950X などが属します。ゲームも作業も余裕で、配信しながらゲーム、動画編集も速い。ただしゲームだけなら下の帯でも十分なことが多いです。

ミドルハイ ― ゲーム性能の主戦場

Ryzen 7 9800X3D、Core Ultra 5 245K、Ryzen 7 9700X など。シングルスレッド性能が高く、強いグラボと組んでも頭打ちになりにくい帯です。とくに X3D モデルは 3D V-Cache のおかげで実ゲーム性能がベンチマーク以上に出ます。

ミドル〜エントリー ― コスパ重視のライン

Ryzen 5 5600、Core i5-12400F など。ミドル帯までのグラボと組むならゲーム性能は十分です。グラボを上位に換える予定があるなら、将来の頭打ちも考えて1ランク上を見ておくと安心です。

Windows 11への対応

Windows 11は、Microsoftの公式対応リストに載っているCPUでないと通常の方法ではアップグレードできません。目安は Intel＝第8世代Core以降、AMD＝Ryzen 2000シリーズ以降 です。このチェッカーでは対象外のCPU（Core i7-4790K、Core i7-6700K）に「Windows 11 公式サポート対象外」と表示しています。なお、CPUが対応していてもTPM 2.0など他の要件は別途必要です。

よくある検索・質問

ゲーム用なら Ryzen 7 9800X3D と Core Ultra 7 265K のどちらですか？

ゲームだけなら 9800X3D が定番です。シングルスレッドの指数では 265K が上ですが、3D V-Cache の効果で実ゲームでは 9800X3D が上回るタイトルが多いです。動画編集などマルチ性能も要るなら 265K に分があります。

RTX 4070 SUPER に合わせるCPUは？

ゲーム指数で 85 前後が目安です。Ryzen 7 9700X、Core i5-14600K、Ryzen 7 7800X3D あたりなら頭打ちを気にせず使えます。各CPUの詳細にある「組み合わせるグラボの目安」も参考にしてください。

コア数が多いほどゲームは速くなりますか？

基本的にはなりません。ゲームの速さはシングルスレッド性能とキャッシュで決まる部分が大きく、コア数は配信・録画・編集など同時作業で効きます。このチェッカーではゲーム指数（シングル基準）とマルチ指数を分けて表示しています。

Ryzen 5 5600 は今でもゲームに使えますか？

使えます。RTX 4060 や RX 7600 クラスのグラボとなら、フルHDゲームは十分快適です。RTX 4070 以上のグラボと組むと、タイトルによってはCPUが頭打ちになり始めます。

Windows 11に対応していないCPUはありますか？

あります。収録46種のうち Core i7-4790K と Core i7-6700K が公式サポート対象外です（Intelは第8世代以降、AMDはRyzen 2000シリーズ以降が目安）。一覧と各CPUの詳細に「対象外」の表示を付けているので、中古で古いCPUを買うときの目安にしてください。

※ 指数は公開ベンチマーク（PassMark）の目安です。実際のfpsはグラボ・メモリ・冷却でも変わります。X3Dモデルは実ゲームで指数以上の性能が出ることがあります。Amazonリンクは該当パーツの検索結果へ移動します。価格・在庫はAmazon側でご確認ください。

このツールについて

CPU性能チェッカーは、CPUを選ぶだけでゲーム性能・マルチ性能の指数と、人気ゲームでの頭打ちのなさ、組み合わせるグラボの目安が一目でわかるツールです。同性能帯のCPUもあわせて表示するので、自作PCや買い替えの比較に使えます。

指数は公開ベンチマーク（PassMark）をもとにした概算で、実機の動作を保証するものではありません。ゲーム判定はシングルスレッド性能からの目安で、実際のfpsはグラボとの組み合わせで決まります。

パーツ別ページ一覧では、収録CPUごとの性能を1パーツ1ページでまとめています。

各パーツのAmazonリンクはアフィリエイトリンクです（Amazonアソシエイト・プログラムを利用しています）。
