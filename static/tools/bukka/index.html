物価タイムマシン

品物を選ぶと、値段の歴史がグラフになります。面白いのはここからで、物差しを変えると景色が逆転します。円では上がって見えるのに、初任給や金で見ると「実は今のほうが安い」――そういう裏返しを探すツールです。

物差し同士も比べられます（たとえば初任給をドルや金で見ると？）

データについて

価格は企業公式の発表・公的統計などで裏が取れた年だけを載せています（データ取得日：2026年11月19日）。裏が取れない年は推測で埋めず、グラフは「最後に確認できた価格が続く」ものとして描いています。初任給は厚労省「賃金構造基本統計調査」（大卒・男。2020年から定義変更があり単純接続できません）、金は田中貴金属の年平均（税抜）、ドル円は年平均、最低賃金は全国加重平均（年度）です。
