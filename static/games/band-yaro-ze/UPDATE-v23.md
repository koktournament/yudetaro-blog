# バンド野郎！ゼ v23

曲名が必ず「○○ / ○○」になる仕様を変更。歌詞・曲調・経験条件の仕組みはv22を維持。

## 曲名の6つの作り方

- 歌詞に実際に現れた名詞・短句：34%
- 歌詞の一節：24%
- 用意した自然な短縮形：16%（対応する句がない場合は短句へ）
- 歌詞中の異なる二つの言葉を「と」「&」でつなぐ：12%
- 主題をほのめかす曲名候補：9%
- 二つの題をスラッシュで並べる：5%

「読みかけのままの季節」→「読みかけの季節」、「聞き返す距離にいてくれよ」→「聞き返す距離」など、短縮は明示した対応表で行う。文字数で途中を切らない。長い二語の組み合わせは一語に戻す。

日本語・英語の主題別の題を各96、計192候補追加。英語主体の曲には英語の題、日本語主体には日本語の題を使う。パート混合・行混合では日本語の題を使用。

曲名の単語候補も経験条件を守る。未経験の武道館・ドームなどが題に紛れ込まない。一般の幻想や恋愛の題は創作の候補であり、内容すべてが実話という意味ではない。

曲名だけの独立した乱数列を使うため、曲名の変更によって歌詞の抽選は変わらない。新規曲はsongDraft.version=5、titleVersion=2。既に保存済みのv1〜v4の曲名・歌詞・Styleは維持。
