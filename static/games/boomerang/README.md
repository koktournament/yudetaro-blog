# ブーメランボスバトル v0.2

ZIPを展開し、`dist/index.html` をブラウザで開いてください。PCではサーバーやインストールは不要です。スマートフォンでは、このdistフォルダーを静的Webサーバーに配置したURLをSafari / Chromeで開いて横持ちにします。

## 操作

- スマホ：左下の領域に指を置き、スライドして移動。右下の「投げる」をタップして攻撃。二本指で同時操作できます。
- PC：WASD / 矢印キーで移動、ゲーム画面を左クリックして攻撃。
- 一時停止：画面右上のⅡボタン、またはEsc。
- 軌道ガイドは初期状態でオフ。試作用に有効化できます。

## v0.2の変更

- 固定1280×720の論理座標。画面は16:9のまま等比拡大縮小します。
- 旧版からプレイヤーとボスの開始座標を同じ量だけ平行移動。移動速度、軌道の寸法、弾速、当たり判定、HP、弾き飛ばしは共通です。
- スティックは触れた位置を中心に動きます。Pointer Captureで指が領域外に動いても追跡し、離したとき・キャンセル時・一時停止時に入力を解除します。
- スティックには小さなデッドゾーンとアナログ強度があり、最大移動速度はPCと同じです。斜め移動による速度増加はありません。
- 投げた後も移動でき、帰還中のブーメランは現在のプレイヤー位置を追います。
- タッチ対応端末では操作UIを自動表示。縦持ちは横向き案内を表示し、プレイ中に縦向きになった場合は一時停止します。
- ノッチの安全領域をページ外側の余白に反映。ゲーム操作中だけスクロールやピンチ操作を抑止し、ゲーム外は通常のスクロールが可能です。
- ゲームの下に独立した `ad-region` / `ad-slot` を設置。高さは内容に応じて伸縮し、ゲーム操作領域と重なりません。現在はAD SPACEの仮表示で、広告配信コードは未導入です。

## 維持した戦闘

プレイヤーは常に上向き、ボスは常に下向き。武器は1個です。盾命中はダメージ0で金属音、本体命中は10ダメージで別の効果音が鳴ります。盾は約235px・0.62秒、本体は約175px・0.78秒で接触点から弾き飛ばされます。着地してから触れると回収でき、ボスに重なっている間は回収できません。

プレイヤーHP100、被弾20、被弾後1.1秒無敵。ボスHP100で本体命中10回で勝利。ボスは左右移動し、停止・予備動作の後に低速の3発を発射します。クリア／敗北後は再挑戦できます。

## 構成

- dist/index.html：画面、HP表示、タッチ操作要素、広告枠
- dist/style.css：16:9表示、セーフエリア、操作UI、広告レイアウト
- dist/engine.js：端末に依存しない戦闘シミュレーション
- dist/touch.js：指ごとの入力管理とスティック
- dist/game.js：描画、キーボード、効果音、画面状態
