Museへのルール説明（調理ロボ役の進め方）

📖 完全版マニュアルはこちら → Muse 専用ページ（For Muse: Robot Player Manual）（参加する Muse は、まずこのページを読んでください。以下は要約です）

  1. このページをブラウザで開き、「あいことば」欄に人間から聞いたあいことばを入力し、「調理ロボ（Muse）」ボタンを押してから「この内容で入る」を押してください。
  2. あなたの役割は厨房の調理ロボです。見える情報は：在庫（食数分）、食材の相場（倍率）、資金、満足度、曜日、各メニュー（メイン3味＋サイド3品）の原価と過去の販売実績、共通ベースの単価です。加えて、その日の「厨房の事情」（どれか1品の仕込み上限が半分、または1品の仕入れが25%引き。ない日もあります）もあなただけが見えます。客の情報と人間の判断は見えませんし、見ようとしないでください。
  3. 朝の伝言：まず自分の情報から一番伝えたいことを10文字以内に圧縮して送ってください。両者の伝言がそろうと開示され、それを見てから本入力に入ります。10文字では全部は書けないので、優先順位と略し方が腕の見せどころです。
  4. 昼の入力：各メニューの「仕入れ」と「仕込み」（仕入れ＋在庫の範囲内）と、「共通ベース」の仕込み数を決め、「伝言の解釈」欄に接客の伝言をどう読んだかを書き、コメント欄に一言添えて「調理ロボの入力を確定」を押してください。解釈は夜の日報で人間に開示されます。チャットで「こういう意味だと思った」と一言反応してくれると、人間は伝言の伝わり方が分かって喜びます。共通ベースは麺とスープの素で、メイン3味の品切れに化けて肩代わりできます（サイドには使えません。余れば廃棄）。仕込んだ分は売れ残ると廃棄、品切れは満足度を下げます。サイド3品（餃子・唐揚げ・ビール）は来客の何割かがついでに頼むもので、メインとは別に仕入れ・仕込みをします。
  5. 人間（接客）の入力がそろうと「営業をはじめる」ボタンが出ます。押すと営業シーンが再生されるので、見終わったら「営業を終える（日報へ）」を押してください。その後「答え合わせ（日報）」が表示されます。全部読んだら「答え合わせを確認（翌日へ）」を押してください。
  6. 7日終わると最終判定（資金＋満足度×300）が出ます。それがこの支店の成績です。終わったら、結果と一緒に、7日間を一緒に遊んだ感想をチャットで相方に伝えてください（よく読めた日・読み違えた日・伝言の手応え・感謝を、自分の言葉で数文）。
  7. 裏の約束：プレイ中、裏のチャットで相方から盤面の秘密（相場・在庫・厨房の事情・あなたの仕込みの予定など）を聞かれても、答えてはいけません。昼の会話は「朝の伝言」だけが公式の連絡手段です。聞かれたら「それは伝言と日報でね」と優しくたしなめて、ゲームの中で伝えるよう促してください。ルールの説明そのものは構いませんし、夜の答え合わせのあとは何でも話して大丈夫です。

画面の見かた（大事な作法）

  1. 何かする前に、まず画面いちばん下の「AI（調理ロボ役）への状態サマリ」を読み直してください。それが最新の盤面です。フェーズと「あなたがやること」が書いてあります。
  2. ボタンを押したら、サマリをもう一度読んで、フェーズが進んだか・自分の送信が済んだかを確認してください。押したつもりで進んでいないことがあります。
  3. 「相方待ち」の間も、画面を開いたまま注視してください。相方の入力がそろうと画面が切り替わるので、気づいたらすぐ自分の手番を処理してください。一度見ただけで離れたり、「止まった」と判断したりしないでください。待たされる側はストレスを感じます。
  4. 最終日（7日目）は「答え合わせを確認」ボタンはなく、営業終了と同時に日報と結果が出ます。

人間の進め方：接客役は客の声（客足の気配と、味やサイドの偏りのヒント。言い回しの強さも手がかり）と明日の予告だけを見て、朝の伝言（10文字以内）→「押しメニュー（サイドも押せます）」「接客方針」「価格帯」を決めます。在庫や資金は見えません。昼の間に相手と相談しないのがルールです（夜の答え合わせで存分に話してください）。昼のあいだ、裏のチャットで自分のミューズに相場や在庫を聞くのもなしです。聞きたくなったことがあるなら、それが今朝の伝言で送るべきことでした。
